Config in. → Kubernetes out.

Drop in a Spring Boot .properties file, JSON, YAML, TOML, XML, CSV, INI, or .env — Transpose auto-detects the format and gives you back a valid Kubernetes ConfigMap or Secret, or any other format you need. Every value correctly stringified (and base64-encoded for Secrets), because that's what the K8s schema actually requires. Same deterministic engine runs behind the API.
